Bilans de la classe

Suivi automatique

Les élèves qui ont saisi un code de suivi envoient leur bilan à votre tableur, sous ce code et sans leur nom. Chargez ici ces bilans, puis votre fichier de correspondance (code, nom) : les noms ne sont ajoutés que dans ce navigateur et ne partent jamais en ligne.

Aucun fichier de correspondance : les élèves apparaissent sous leur code.
Créer des codes de suivi pour la classe

Chaque code est tiré au hasard. Le fichier téléchargé contient les codes et une colonne « Nom » à remplir : c'est votre fichier de correspondance, à garder sur votre ordinateur. Collez seulement la liste des codes dans la colonne A d'un onglet « Codes » du tableur : les autres codes seront refusés.

Dépose ici les bilans envoyés par les élèves (fichiers bilan-….json) ou colle le texte qu’ils t’ont copié. Rien n’est envoyé sur internet : les bilans sont lus dans ce navigateur et oubliés quand tu fermes la page.
